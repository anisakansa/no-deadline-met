## The line

> I was five minutes from done for three days straight — the last five minutes just kept renewing.

96 characters, one sentence, no setup. The joke turns a feeling everyone knows — being five minutes from done — into the excuse itself: the last five minutes kept renewing for three days, so the deadline never stood a chance. Plain words, no tech cliché, no laptop update, no dog ate it. It sounds like something a person actually says when cornered, exaggerated just enough to be funny.
